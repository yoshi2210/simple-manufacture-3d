# VELO-32 KESTREL — 1/32 4WD レーサーの設計開発事務所＆製造ライン（デジタルツイン）

架空メーカー **VELO WORKS** が、ミニ四駆タイプの 1/32 4WD レーサー「VELO-32 KESTREL」を企画・設計し、量産立上げを迎えるまでを、1 つのブラウザページで再現したデモです。
製品データ・工程・品質・原価・サプライチェーン・組織は、すべて `data/company.json` にまとめてあり、画面上の数字はこのデータからブラウザ内で計算しています。

`web/index.html` を開くだけで動きます（three.js を CDN から読み込むため、ネット接続が必要です）。

## 画面構成
| タブ | 内容 |
|---|---|
| 🏢 キャンパス | 設計開発事務所（18 部門・132 名の席、デザインレビュー室、CAE 室、3 レーンのテストコース、試作・電気・品質ラボ、風洞）と工場（射出成形 6 台、SMT ライン、組立ライン A10–A90、EOL ローラーダイナモ、梱包・パレタイズ、倉庫・出荷、AGV）。部門ラベルをタップすると、その部門のミッション・KPI・担当プロセスを表示 |
| 🎨 デザインスタジオ | 実寸（mm）の 3D 車体を大きく表示。分解スライダー、部品クリックで部品カード（材質・工法・原価内訳・特殊特性・コントロールプラン・DFMEA・ECN）、規則エンベロープ（165×105×70 mm）と適合チェック、重心、モーター×ギヤ比の走行性能シミュレーション |
| 🌬 空力 CFD | 車体中心断面の 2D 格子ボルツマン法（D2Q9）をブラウザ内でライブ計算。3 ボディを自動スイープし、抗力比を性能計算に反映 |
| 📐 開発プロセス | APQP 5 フェーズ・6 ゲートの日程、次ゲートの判定基準、デザインレビュー、PPAP 18 要素、電装・FW の V 字プロセス、ECN と設計変更フロー |
| ✅ 品質 | DFMEA / PFMEA（AIAG-VDA のアクションプライオリティを自動判定）、コントロールプラン（Cpk 自動計算）、ライブ SPC、DVP&R、8D、サプライヤー評価 |
| 📦 SCM・MRP | 販売計画から品目別の MRP（総所要量→予定在庫→計画受入→計画発注、リードタイム不足の例外）、需要と生産能力 |
| 💴 原価 | E-BOM 23 行の積上げ原価（成形品＝樹脂＋成形機チャージ＋金型償却、基板＝部品＋SMT、購入品＝見積）、目標原価との差、VA/VE、バリエーション別粗利 |
| 🏛 バックオフィス | 全部門のミッション・システム・KPI、8 つのバリューストリーム（I2L / P2P / PR2P / O2C / R2R / H2R / I2R / CHG）のスイムレーンと仕掛り件数 |

キャンパスでは、受注・発注・出荷・受入検査・SPC・問い合わせ・経理・設計変更のイベントが流れ続けます（ライン動作は実時間の 4 倍速）。

## 製品の考え方
- **モーターは購入品**: 130 サイズ DC モーターを 3 グレード（スタンダード / ハイ回転 / トルク）でサプライヤーから購入し、受入検査で無負荷回転数を抜取確認
- **独自基板「VX-Link」**: BLE SoC・6 軸 IMU・ホールセンサー・MOSFET ソフトスタート（120 ms）。社内 SMT ラインで実装し、EOL で待機電流とソフトスタートを全数検査。FW は V 字プロセス（Automotive SPICE 相当）で開発
- **規則**: タミヤ ミニ四駆公認競技会規則の車体寸法・重量（全長 ≤ 165、全幅 ≤ 105、全高 ≤ 70 mm、最低地上高 ≥ 1 mm、タイヤ径 22–35 mm、幅 8–26 mm、重量 ≥ 90 g）をコース互換の設計制約として採用

## 注意
「ミニ四駆」は株式会社タミヤの登録商標で、本デモはタミヤとは関係ありません。公認競技会規則では自作シャーシ・自作ボディや、タミヤ製以外のモーター・電池は認められないため、この製品は公認レースの対象外という設定です。
会社・サプライヤー・顧客はすべて架空、数値はデモ用の代表値です。CFD は 2 次元・低レイノルズ数の定性的な比較で、性能計算には相対値（抗力比）のみを使っています。

## ビルドと検証
```bash
python mini4wd/tests/test_company_data.py   # 規則適合・タクト・設備能力・原価の整合チェック
python mini4wd/web/build.py                 # web/src/*.js と data/company.json を 1 ファイルの index.html に
```
ソースは `web/src/`（01_core → 07_app の順に連結）と `web/template.html`。原価の計算式はテスト（Python）とブラウザ（`05_studio.js` の `COST`）で同じものを使っています。
