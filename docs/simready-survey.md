## SimReady に無いもの と その代わり
| 無いもの | 代わり |
|---|---|
| エンジンブロック / 完成 V8 エンジン | ブロックは手続き生成のまま。SimReady の部品を各ステーションで組み付ける |
| 完成車 | 車体フレームと外装部品の組み合わせで構成 |
| AMR / AGV、フォークリフト | Isaac Sim 付属のロボット（Nova Carter など）を使う |
| 溶接ガン・塗装ガン、塗装ブース、天井ハンガー | 手続き生成のまま |
| 工場の建屋 | 手続き生成。将来は実工場の CAD を Isaac Sim 6.0.1 のアセット変換（JT・HOOPS・DGN など）で取り込む |

## Isaac Sim で動かせるか
- **ロボット**: Comau N-220-27 は関節に駆動が付いているので、関節の目標角度を渡すだけで動く。
  ただし逆運動学（手先位置から関節角を求める）の設定ファイルは同梱されていない。対応方法は 2 つ。
  1. PhysX が出すヤコビ行列（`Articulation.get_jacobian_matrices()`）を使った汎用の差分 IK。どのロボットにも設定なしで使える
  2. Isaac Sim 6 の cuMotion 用ロボット設定を作る（干渉回避付きの軌道計画まで使える）
- **部品**: PhysX・Newton・MuJoCo 向けの物理ペイロードが同梱されている（クランクシャフトで確認）。物理的につかんで置ける。
- **コンベア**: Isaac Sim の Conveyor Belt Utility が剛体をコンベア化する（表面速度で物を運ぶ）。`conveyor_belt_a02` に適用できる見込み。
- **バージョン**: Isaac Sim 6.0 以降は、コンテンツブラウザに SimReady の検索が組み込まれ、FANUC・Comau のロボットもアセットカタログに入った。
  一方で、今のスクリプトが使っている `isaacsim.core.api` と Lula は 6.0 で非推奨になった（削除はされていない）。
  `isaacsim.core.experimental` と cuMotion への移行が必要。NGC のコンテナは 6.1.0 が公開されている。

## Airsup を使わない場合の構成
Airsup（airsup.ai）は、現地調査をもとに工場のデジタルツインを構築・運用する有料サービス。公開 API と無料枠は無い。
同じ役割を次の組み合わせで置き換える。

| Airsup の機能 | このリポジトリでの置き換え |
|---|---|
| 現場の取り込み | 当面は SimReady アセットで代用。実工場の場合は CAD を Isaac Sim に取り込む |
| 3D・ロボット・物理シミュレーション | Isaac Sim ＋ SimReady |
| 生産量・ボトルネックの評価 | 今は固定タクトのモデル。工程ごとの所要時間をばらつかせる離散イベントシミュレーション（SimPy など）を追加予定 |
| チームで見る | ブラウザ版。Isaac Sim 側は Docker Compose のブラウザビューア（WebRTC） |
